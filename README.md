# Decisiones De Diseño

El proyecto fue diseñado siguiendo una arquitectura en capas para lograr una estructura modular y clara. Se utilizó Express.js para construir la API REST, dividiendo el código en carpetas: routes, controllers, services y repositories. Las rutas (routes) definen los endpoints y redirigen las solicitudes al controller correspondiente, los controllers manejan las peticiones HTTP sin incluir lógica de negocio, los services implementan la lógica de negocio y los repositories gestionan el acceso a los datos (en este caso, almacenados en memoria). Esta separación facilita el mantenimiento, las pruebas y futuras integraciones con bases de datos reales
